# RD Visuals (phone)

Reaction-diffusion visuals for Android Chrome (Pixel).

## Permanent URL (GitHub Pages)

Repo: https://github.com/caseypaulzammit-blip/rd-visuals

**One-time enable (required):** open the repo → **Settings** → **Pages** → under *Build and deployment* set **Source** to **GitHub Actions**. Then Actions → **Deploy GitHub Pages** → **Run workflow**.

After that the site is: **https://caseypaulzammit-blip.github.io/rd-visuals/**

(The GitHub App token cannot create a Pages site by itself — `Create Pages site failed: Resource not accessible by integration`.)

## Controls
- Tap canvas = show/hide UI
- Drag = paint
- Photo = camera / gallery
- Record Loop = WebM
- Mic = bass kicks only (no steady sim advection)

## Add to Home Screen
Chrome menu → **Add to Home Screen** / **Install app** for fullscreen PWA.
